# 🙋🏽 Peterson Araujo

### Olá! Bem-vindo ao meu perfil no GitHub 👋

**`Desenvolvedor Backend`**

<p style="text-align: justify;">
  Sou estudante de Análise e Desenvolvimento de Sistemas pela UNOPAR e apaixonado por tecnologia, desenvolvimento de software e aprendizado contínuo. Atuo no desenvolvimento de soluções back-end com Java e Spring Boot, aplicando boas práticas de arquitetura para construir aplicações escaláveis, desacopladas e de fácil manutenção. Possuo experiência no desenvolvimento de APIs REST, integração com bancos de dados SQL, implementação de microsserviços, utilização de Redis para cache e gerenciamento de dependências utilizando Maven. Tenho experiência com ferramentas e tecnologias como Docker, Git, GitHub, DBeaver, Azure, além da criação de testes unitários com JUnit 5, sempre buscando garantir qualidade, desempenho e confiabilidade nas aplicações. Além do ecossistema Java, também possuo experiência com a Microsoft Power Platform, desenvolvendo soluções utilizando Power Apps, Power Automate, Dataverse e personalizações no SharePoint, contribuindo para a automação de processos e transformação digital. Estou sempre em busca de novos desafios, aprimorando meus conhecimentos e desenvolvendo soluções que gerem valor por meio da tecnologia.
</p>
